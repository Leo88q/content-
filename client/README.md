# /client — мобильное приложение

**Статус: пусто намеренно.** Старт — Фаза 4.

## Что здесь появится

Мобайл-центричное приложение для воркеров и заказчиков: лента заданий, флоу загрузки клипа, кошелёк, история заработка.

## Интеграции

- **Solana Mobile Wallet Adapter** — подпись на мобильных клиентах, поддержка Seed Vault на Seeker
- `@solana/kit` **8.3.0** (не v5.x, как в промпте — см. ADR-0005)
- типизированный клиент программы — генерация из IDL через Codama 1.10.2
- согласие на передачу прав подписывается в UI, хеш уходит в `SubmissionAccount.consent_hash`

## Открытые вопросы

Q8 (PWA + Capacitor vs React Native/Expo bare), Q12 (требуется ли Seeker/Seed Vault для участия). См. `docs/OPEN_QUESTIONS.md`.

## dApp Store

Для подачи нужен подписанный нативный Android APK — при любом выборе из Q8 потребуется нативная обёртка. Паблишинг через `@solana-mobile/dapp-store-cli` 1.0.1 (`engines.node >= 18`).
