# /programs — on-chain (Anchor)

**Статус: пусто намеренно.** Код не пишется до закрытия Q17, Q18, Q19 в `docs/OPEN_QUESTIONS.md`.

## Что здесь появится в Фазе 2

Одна Anchor-программа (рабочее имя — до выбора нового названия продукта, см. PRD §Введение):

- `TaskAccount` — бриф, тиры награды, `max_claims`, дедлайн, статус
- `ClaimAccount` — PDA `["claim", task, worker]`, лок на N часов
- `SubmissionAccount` — хеш медиа, URI, `consent_hash`, статус модерации, `awarded_tier_id`
- инструкции: `create_task` · `claim` · `submit` · `moderate(tier_id)` · `payout` · `refund_expired`

Схема и обоснование отличий от мастер-промпта — в [`PRD.md`](../PRD.md) §4 и в ADR-0002/0003/0004.

## Тулчейн (зафиксирован, ADR-0005)

Anchor **1.2.0** · Solana CLI **4.1.2** · `solana-*` крейты линии `^3` (не поднимать до `^4`) · Rust 1.89+ · тесты: LiteSVM/Mollusk + Surfpool (`anchor test` в 1.x гоняет Surfpool по умолчанию).

## ⚠️ Блокер сборки в текущей среде

Проверено 2026-09-14: `cargo`, `rustc`, `anchor`, `solana`, `docker` в этой песочнице **отсутствуют**. Пока тулчейн не установлен, программа здесь не собирается и не тестируется. Не принимать on-chain код из этой среды за проверенный.

## Правила

- Никаких приватных ключей в репозитории — только env/секрет-менеджер (см. `/.gitignore`).
- Любое изменение инструкции — только с юнит- и интеграционными тестами до мержа.
- Никакого деплоя в mainnet-beta без явного подтверждения человека.
