# /backend — оффчейн-сервисы

**Статус: пусто намеренно.** Старт — Фаза 3.

## Что здесь появится

- CMS брифов и очередь заданий
- API приёма сабмишенов, загрузка медиа в Arweave (Turbo) / IPFS + S3-зеркало
- пайплайн авто-префильтра: формат, длительность, NSFW, эвристика копирайта
- дашборд модератора с аудит-логом решений (кто, когда, какой тир, причина отказа)
- нотификации (push / telegram / email)
- атрибуция: UTM-метки, трекинг установок игр и коннектов кошелька с привязкой к клипу

## Стек (мастер-промпт §4)

Node.js / TypeScript · Postgres · BullMQ + Redis
