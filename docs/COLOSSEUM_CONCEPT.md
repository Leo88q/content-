# COLOSSEUM — маркетинг как зрелищный рынок ставок на удержание

- **Дата:** 2026-09-21
- **Статус:** концепт-предложение (эскалация `WEB3_PROPOSITION.md`). Не ADR, не решение.
- **Отношение к Stayk:** Stayk — расчётный слой (вестинг по retention-кривой, атрибуционный граф, CPRW). Colosseum — взрывной слой поверх: зрелище, рынки, публичные споры. Без Stayk это казино; без Colosseum Stayk — невидимый B2B-инструмент.

| Quest-платформы: 100K DAW → <20K после конца наград; наёмники уходят в день выплаты | hackernoon.com/why-most-web3-communities-are-built-to-collapse |
| >70% органики Telegram mini-apps — peer-рефералы, не реклама | whimsygames.co (Telegram mini apps gaming) |

Вывод: внимание в крипто собирается не вокруг «кампаний», а вокруг
**зрелищ с финансовой ставкой**. Colosseum переносит эту механику
в маркетинг: кампания перестаёт быть строкой бюджета и становится событием,
на которое смотрят, на которое ставят и за которое дерутся.

## 2. Концепт

> **COLOSSEUM — первая маркетинговая платформа, на которую можно ставить.
> И против которой можно ставить.**
>
> Кампании — гладиаторские бои гильдий креаторов. Зрители ставят на исход
> по верифицируемым метрикам удержания. Держатели ставок сами становятся
> дистрибуцией кампании. Суды по накрутке — публичное шоу. Все выплаты
> оседают на retention-кривой Stayk: наше казино платит только за
> доказуемо оставшихся пользователей.

### 2.1 Слой 1 — Арена (маркетинг как киберспорт)

- Кампания запускается как **live-турнир**: гильдии креаторов (3–10 команд) соревнуются за эскроу-призовой фонд в реальном времени.
- Публичный лидерборд обновляется по верифицируемым событиям: приведённые кошельки, целевые действия, D3/D7-активность когорт. Никаких «заявок» — только данные графа.
- Зрительский слой: стримы хода кампании, касты, разбор тактик гильдий, еженедельные «бойцовские вечера» — топ-гильдии против топ-кампаний.
- **Функция зрелища — дистрибуция:** просмотр матча бесплатен для проекта, но каждый зритель видит продукт в действии (лидерборд ведёт в игру/протокол одним тапом).

### 2.2 Слой 2 — Рынки кампаний (ядро изобретения)

Каждая кампания получает торгуемый рынок исхода:

```
РЫНОК: «Кампания [X] приведёт ≥ N кошельков, активных на D30,
        при CPRW ≤ $P?»
ДА / НЕТ. Расчёт — данные атрибуционного графа Stayk, не цена оракула.
Эскроу расчёта — призовой фонд кампании + пул ликвидности рынка.
```

**Переворот, которого нет ни у кого:**

| Платформа | Кто держит актив | Что делает держатель |
|---|---|---|
| pump.fun / мемкоины | холдер токена | шиллит актив, не привязанный к реальному исходу |
| Polymarket | беттор на внешнее событие | ждёт; событие от его ставки не меняется |
| **Colosseum** | беттор на исход кампании | **его ставка растёт от успеха кампании → он сам приводит трафик, шерит, защищает в спорах. Держатель позиции = волонтёр маркетингового отдела** |

Дистрибуция становится **эндогенной**: чем больше людей поставило на успех
кампании, тем больше у кампании бесплатных дистрибьюторов с финансовой
мотивацией. Проект покупает не показы — он покупает **армию держателей**.

Механика рынка:
- Формат — prediction market на верифицируемую метрику (не security: ставка на измеримое событие кампании, расчёт в USDC, как событийные рынки Polymarket).
- Цена YES = рыночная оценка вероятности успеха = **народный аудит кампании в реальном времени**. Падение цены после старта — ранний сигнал, что проект надувает щеки; для честных проектов цена — бесплатный PR («рынок верит в нас на 87%»).
- Ликвидность seed-ит проект (maker-стимулы первые 72 часа) + AMM по bonding curve для мелких рынков.
- **Circuit breakers:** позиция самого проекта и аффилированных кошельков (по графу связей) ограничена и маркируется публично — самонакрутка индекса видна всем.
- Собственного токена платформы НЕТ (принцип W5). Расчёт — USDC/стейблкоины. «HYPE-индекс» — это цена рынка, а не токен в кошельке.

### 2.3 Слой 3 — Суд Retention (хейт как контент и как проверка)

- Любой может внести **залог обвинения** (bond, например $500–5000) и выдвинуть структурированный claim: «когорта кампании X на 78% — кластер фермы, вот связи кошельков».
- Claim рассматривается против данных графа + ончейн-кластерного анализа. Публично, с таймлайном, с возможностью проекта ответить своим залогом.
- Исход: обвинение доказано → обвинитель забирает штраф из эскроу кампании, кампания получает метку «FARMED» в публичном реестре; опровергнуто → залог обвинителя сгорает в пользу кампании.
- **Правила, снижающие юридический риск:** обвинения только о верифицируемых ончейн-данных и когортах, никаких персональных утверждений («X — скамер» запрещено, «когорта X содержит N кошельков с паттерном Y» — разрешено); шаблон claim'а фиксирован; каждый суд — нумерованное публичное дело.
- Эффект: хейтеры перестают быть издержкой — они короткая позиция с залогом. Честные проекты проходят через суды и получают **публично доказанную честность** — актив, который нельзя купить ни у одного KOL.

### 2.4 Слой 4 — Расчёт (якорь реальности, наследие Stayk)

- Все выплаты гильдиям — по вестинг-кривой Stayk (0% за connect → 100% за D30-активность). Арена может греметь, но деньги двигаются только за удержание.
- Расчёт рынков — по фактическим данным графа на D30 после окончания кампании, автоматически, из эскроу.
- Публичный реестр: каждый проект несёт пожизненную карточку — история кампаний, CPRW-динамика, пройденные суды, рыночные цены исходов. **Репутация как немаркетируемый актив.**

## 3. Виральные петли (почему растёт само)

1. **Спектакль → контент.** Бои, суды, обвалы и пампы рынков производят бесконечную драму, которую участники распространяют сами (каждый скриншот лидерборда — реклама платформы).
2. **Ставка → дистрибуция.** Каждый держатель YES — волонтёр-маркетолог кампании. Рост рынка = рост армии.
3. **Хейт → трафик.** Обвинение с залогом приводит на платформу аудиторию обвинителя; суд приводит аудиторию проекта; вердикт приводит прессу.
4. **Репутация → lock-in.** Трек-рекорд гильдии и карточка проекта не переносятся к конкуренту.
5. **Бенчмарки → PR.** Ежеквартальный «State of Hype vs Retention»: публичный отчёт, где рыночные цены кампаний сверяются с фактом — earned media в среде, где paid media задушен (apcollective).

## 4. Экономика платформы

| Поток | Источник |
|---|---|
| Комиссия исходов 10–15% | эскроу кампаний (наследует Stayk) |
| Комиссия рынков 1–2% с объёма + spread seed-пула | рынки кампаний |
| Залогы судов: доля платформы 10–20% | проигравшие bond'ы |
| SaaS: доступ к графу, бенчмаркам, карточкам конкурентов | маркетинг-команды, фонды |
| Premium-места на Арене: слоты топ-кампаний в прайм-тайм «бойцовских вечеров» | проекты |

Юнит-экономика взрывного слоя: зритель со ставкой приносит не только
комиссию, но и **дистрибуцию** — CAC платформы падает с ростом объёма
рынков (каждый новый беттор — канал привлечения для кампаний, которые он
держит).

## 5. Юридический контур — ОБЯЗАТЕЛЬНО К ПРОЧТЕНИЮ

Это самая рискованная часть концепта. «Взрывоопасность» буквальна:

1. **Рынки на деньги = гемблинг/предикшн-регуляторика.** Polymarket заходил в США только через CFTC-клиренс; в ЕС/НЛ — режим азартных игр. Митигация по фазам: фаза 0 — бумажные рынки (очки, без денег, юридически — лидерборд); фаза 1 — skill-based призы Арены (соревнование по измеримому мастерству, во многих юрисдикциях не гемблинг — требует подтверждения юристом); фаза 2 — денежные рынки только после заключения и только в разрешённых юрисдикциях (гео-гейт).
2. **Суды = риск диффамации.** Митигация: фиксированные шаблоны claim'ов только о данных, псевдонимность кошельков, дисклеймер «анализ паттернов, не утверждение о лицах», юр-обзор шаблона до первого суда.
3. **HYPE-индекс кампании может быть квалифицирован как дериватив/security.** Митигация: расчёт в USDC по измеримому нефинансовому событию (аналог событийных рынков), запрет вторичного обращения «позиций» как токенов, отсутствие токена платформы.
4. **Манипуляции рынком** (проект пампит собственный индекс): circuit breakers, публичная маркировка аффилированных кошельков, расчёт строго по графу, а не по цене.
5. **AML/KYC пороги** для денежных фаз (наследует Q12 SixSec).

Правило мастер-промпта SixSec сохраняется в полной силе: любой пробел,
касающийся денег, юрриска или mainnet, — остановиться и спросить.

## 6. Поэтапная эскалация (каждая фаза сама по себе продукт)

| Фаза | Что | Деньги | Юр-статус | Цель фазы |
|---|---|---|---|---|
| 0 | **Бумажный Colosseum:** лидерборды кампаний + рынки на очки + публичные карточки | нет | лидерборд/аналитика | проверить зрительский аппетит и виральность формата без регуляторики |
| 1 | **Арена:** турниры гильдий, призовые из эскроу проектов, расчёт по Stayk-кривой, стримы | эскроу проектов, skill-based призы | киберспорт-конкурс (проверить юристом) | первые честные CPRW + гильдии с трек-рекордом |
| 2 | **Рынки на деньги** в разрешённых юрисдикциях | USDC-пулы | предикшн-режим (юрзаключение + гео-гейт) | эндогенная дистрибуция, народный аудит кампаний |
| 3 | **Суды Retention** с залогами | bonds | шаблон claim'ов после юр-обзора | хейт → трафик; публично доказанная честность как продукт |

Откат любой фазы не убивает предыдущие: фаза 0 монетизируется SaaS-ом,
фаза 1 — комиссиями исходов. Хайп наращивается слоями, риск — тоже слоями.

## 7. MVP фазы 0–1 (6 недель, до любых смарт-контрактов)

| Недели | Что делаем | Go/no-go |
|---|---|---|
| 1–2 | Лендинг «поставь на кампанию — бумажно»; три игры заказчика как первые «бойцы»; ручной граф (БД игры + UTM) | ≥500 участников бумажного рынка; шаринг лидерборда ≥10% юзеров |
| 3–4 | Первый турнир 3 гильдий на одну игру: реальный эскроу в USDC, выплаты вручную по D7-кривой (укороченной), стрим-разборы | гильдии вернулись на второй турнир; CPRW турнира посчитан |
| 5–6 | Публичный отчёт турнира + первый «бумажный суд» (claim без денег, разбор когорт публично) | ≥1 сторонний проект подал заявку на кампанию; пресса/КТ подобрала отчёт |

Смарт-контракты (эскроу-арена, рынки) — только после недели 6 и юрзаключения.

## 8. Метрики взрывного слоя

- Северная звезда фазы 0–1: **watched-hours кампаний** × доля зрителей, совершивших целевое действие (attention → conversion).
- Рынки: объём, open interest, доля держателей YES, которые сами привели ≥1 кошелёк («дистрибьюторская конверсия ставки» — метрика, которой нет ни у кого).
- Суды: число claim'ов, доля доказанных, трафик на дела.
- Сквозная: CPRW кампаний Colosseum против CPRW тех же проектов до Colosseum.
