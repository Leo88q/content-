# VACUUM v2 — web-пылесос органического трафика (прокладка для 4 игр, БЕЗ Telegram)

- **Дата:** 2026-09-21 · **Ревизия:** 2 (заказчик: «давай без телеграмма, там глухо» — Telegram убран из основания; сохранён только как опциональный дешёвый адд-он вне критического пути)
- **Статус:** концепт-предложение. Не ADR, не решение.
- **Позиция в стеке:** VACUUM — слой аудитории (consumer media) перед `WEB3_PROPOSITION.md` (Stayk) и `COLOSSEUM_CONCEPT.md`. Порядок: сначала собственное внимание, потом B2B-слои из него.

---

## 1. Рефрейм (без изменений от v1)

Не строить площадку для чужого маркетинга, а **построить медиа-пылесос,
владеющий вниманием сам**: монетизация изнутри своими 4 играми, позже —
открытие инвентаря наружу. Модель доказана TradingView (виджеты+SEO),
DexScreener (чарты → promoted-слоты), CoinGecko/CMC (листинги, поиск).
Наше отличие: инвентарь сначала заполнен собственными играми —
медиа-компания, владеющая своим главным рекламодателем.

## 2. Основание без Telegram: три опоры

| Опора | Что это | Почему держит вес |
|---|---|---|
| **Web-терминал + программный SEO/GEO** | сайт-пылесос: страница на каждый актив (чарт + AI-нарратив + FAQ-блок под AI-поиск), PWA с push, портфель по кошельку | поисковый спрос существует сам и накапливается годами; «spikes don't compound» — SEO compounding; единственный канал, который нельзя отключить одним баном |
| **X (Crypto Twitter)** | авто-каналы фабрики через официальный API: карточки движений, «история дня», алерт-посты | крипто-аудитория живёт на X; автопостинг в СОБСТВЕННЫЕ аккаунты через API — легально и полностью автоматизировано; X остаётся «верхом каждой крипто-воронки» (guerrillabuzz) |
| **Фабрика коротких видео** | автогенерация 15–30-сек motion-видео из данных: анимация чарта + AI-войсовер «что случилось и почему» → TikTok / YouTube Shorts / Reels | алгоритмы коротких видео дают бесплатные охваты новым аккаунтам с удерживающим контентом; «драма рынка за 15 секунд» — один из самых bingeable форматов; себестоимость видео ≈ центы (рендер + TTS), публикация в собственные каналы |

Discord остаётся как **канал эмбедов** (виджеты чартов на серверах
комьюнити — каждая встройка это вечный сифон трафика, модель TradingView
widgets), не как база.

Telegram: вне критического пути. Если позже понадобится — inline-бот
подключается за дни и ничего в архитектуре не требует переделывать
(API ядра одинаков для всех поверхностей).

## 3. Почему график — идеальный контент (ядро аргумента, без изменений)

1. **Данные генерируют контент сами:** актив = страница, движение = событие, событие = карточка/видео. Маржинальная себестоимость ≈ $0.001 (текст) / ≈ $0.01–0.05 (видео: шаблонный рендер + TTS).
2. **Свежесть 24/7:** рынок не спит → «постоянный трафик» — свойство продукта, а не бюджета.
3. **График — шеринговый артефакт:** флекс профитом / нытьё об убытке; скриншот и видео с водяным знаком = бесплатная дистрибуция.
4. **SEO/GEO long-tail:** миллионы запросов «[token] price chart», «[NFT] floor»; в 2026 добавился GEO — ответы AI-ассистентов цитируют структурированные страницы с данными.
5. **Алерты = push-канал и лиды:** Web Push + email (PWA), подключённый кошелёк = лид для CRM-ретаргетинга играми.

## 4. Продукт

**Ядро — web-терминал (PWA, installable):**
- чарты ниши (свечи, объёмы, сделки, холдеры) — быстрые, мобильные;
- «график, который разговаривает»: под каждым чартом авто-нарратив (AI): что произошло, кто двигает, контекст — отличие от молчаливого DexScreener;
- алерты: цена/объём/аномалия → Web Push + email;
- портфель и PnL-карточки по подключённому кошельку (главный шеринговый артефакт, watermark + ссылка);
- каждая страница актива — программная SEO-страница (чарт + нарратив + FAQ + JSON-LD).

**Фабрика контента (конвейер, люди только на QC):**

```
данные (GeckoTerminal/Birdeye) → детектор событий (пороги/аномалии)
  → шаблон или LLM-нарратив (текст, скрипт)
  → рендер: карточка (PNG/OG) + motion-видео (15–30с, TTS-войсовер)
  → очередь публикации (один тап одобрения редактора)
  → X API / YouTube Data API (авто) ; TikTok Content Posting API
     (через одобренное приложение, либо полуавто: очередь → ручной пост)
  → deep link на страницу актива в терминале
```

Каждое видео/карточка ведут на свою SEO-страницу: короткий видео-охват
конвертируется в поисково-накапливаемый актив. Контент работает дважды.

**Честно про автоматизацию публикации:** X и YouTube — полностью авто
через официальные API в собственные каналы. TikTok — Content Posting API
требует прохождения app review; до одобрения — полуавтомат (фабрика
производит, человек жмёт «опубликовать» из очереди 2 минуты в день).
Никаких бот-сеток чужих аккаунтов: серая автоматизация = бан-риск
и смерть домена.

**Себестоимость фабрики (оценка на 100 видео + 1000 карточек в день):**
LLM ~$10–30/день, рендер-видео ~$20–50/день (GPU-free: motion-templates
на CPU), данные free-tier → $0, X API tier ~$100–200/мес. Итого ~$1.5–3K/мес
за поток, который у KOL-агентства стоил бы $50–100K/мес и не накапливался.

## 6. Рекламный инвентарь для 4 игр (без изменений v1, web-нативно)

Правило прокладки: **utility-first, ≤1 ad-слот на 5 полезных действий**;
слот, роняющий retention терминала, выключается по A/B.

| Слот | Формат |
|---|---|
| Родные активы | токены/NFT-полы 4 игр — enriched-страницы («что за игра», CTA «играть», deep link с UTM) → SEO-запросы по активам игр ведут прямо в игры |
| Related-карточки | под чартом game-сектора — карточка релевантной игры |
| Playable-интерстишал | 6-секундная играбельная HTML5-сцена между переключениями чартов; награда — предмет из игры (web-нативно, без сторов) |
| Квест-анлоки | «3 минуты в игре X = премиум-алерт навсегда» — реклама, за которую благодарят |
| Wallet-CRM | сегменты по ончейн-поведению → email/push-ретаргетинг конкретной игрой |
| Promoted (позже) | «Trending» с пометкой — внешний B2B-revenue по модели DexScreener |

## 7. Ниша (без изменений вывода v1)

Клин: **«говорящие чарты»** — web-терминал + фабрика видео с AI-нарративом,
где game-сектор (4 игры) — обогащённая витрина. Не лобовая атака на
DexScreener (red ocean, веб-гигант), а занятая пустая позиция «истории
за цифрами» на X и в коротких видео + GameFi-витрина, которой после
смерти DappRadar (ноябрь 2025) почти никто не делает.

Название — отдельная процедура (по образцу ADR-0008).

## 8. Холодный старт (6 недель, v2)

| Недели | Что | Go/no-go |
|---|---|---|
| 1 | SEO-билд: 2–5K программных страниц (game-сектор + топ активов ниши) на free-фиде; OG-карточки с водяным знаком | индексация пошла; первый поисковый трафик |
| 2 | Терминал MVP: чарты + нарративы + алерты (Web Push/email) + портфель | D1 сессий ≥ 25% |
| 3 | Фабрика видео: конвейер «событие → 15–30с видео»; 3–5 собственных аккаунтов Shorts/Reels/TikTok, 20–50 видео/день | ≥1 видео/неделю с органическим охватом >10K; CTR в терминал ≥ 1% |
| 4 | Инвентарь игр: enriched-страницы 4 игр, related-слоты, первый playable-интерстишал | конверсия пылесос→игра измерена; CTR слота > 2% |
| 5 | X авто-каналы через API; виджеты для Discord-комьюнити; PnL-карточки | ≥20 эмбедов; K-фактор шеринга > 0.1 |
| 6 | Квест-анлоки; когортный отчёт retention; Spark Ads только на видео-победители | D7 терминала ≥ 20%; ≥1 игра получила измеримые установки из пылесоса |

Бюджет пилота: данные free → $0; LLM+рендер ~$500–900/мес; X API ~$100–200/мес;
инфраструктура ~$200/мес; Spark Ads тест ~$300–500. **Итого ~$2–3K за 6 недель.**

## 9. Юнит-экономика (v2)

- CAC → 0 асимптотически: петли 1–5 без медиа-байинга; платно догреваются только уже доказанные органикой видео.
- Себестоимость контента: карточка ~$0.001, видео ~$0.01–0.05 — против $500–5000 за KOL-пост.
- LTV: алерт-подписчик возвращается ежедневно (рынок 24/7); wallet+email CRM допродаёт игры бесконечно.
- Монетизация по этапам: (0) свои игры бесплатно для себя; (1) promoted-слоты внешним за USDC; (2) premium-подписка (pro-алерты, глубина данных); (3) B2B-слой Stayk — продажа инвентаря с расчётом по retention собственной аудитории.

## 11.5. Ревизия 3 (реализовано 2026-09-21): фабрика v3 в бою

Концепт перестал быть концептом: `site/` + `.github/workflows/factory.yml`
работают на каждом push, после мержа PR #3 — cron каждые 4 часа.
Добавлено поверх ревизии 2 и проверено боевыми прогонами:

- **Whale-радар:** лента сделок ≥ $25K (trades API, 1000 сделок = широкое окно);
  китовые фрагменты в нарративах, WHALE BUY/SELL-пилюли на карточках,
  live-лента выбранного пула в терминале.
- **«Ганнеры дня»:** ежедневная SEO-страница `site/gainers/` (latest.html) —
  свежий поисковый контент каждый прогон, long-tail растёт.
- **Видео-фабрика:** вертикальные 15с mp4 (Pillow-кадры + ffmpeg): анимированный
  спарклайн, субтитры-нарратив, водяной знак. **mp4 не коммитятся** (конвенция
  репо `*.mp4` в .gitignore) — это CI-артефакт `videos-for-posting` (30 дней):
  очередь постинга в TikTok/Shorts/Reels, человек забирает и публикует.
  Витрина в терминале есть, но скрывается, если mp4 не локальны.
- **Бумажные прогнозы «угадай свечу 1ч»:** retention-петля без денег и
  регуляторики: стрики, точность, карточка результатов для шеринга (localStorage).
- Инфраструктурные уроки прогонов: exit 128 = `git add` игнорируемого pathspec
  (теперь `git add -A site/`), concurrency cancel-in-progress=true (фабрике
  важен только свежий прогон), guard'ы Pillow/ffmpeg — вежливый скип.

## 11.6. Ревизия 4 (реализовано 2026-09-21): адаптация под GEO (Generative Engine Optimization)

В 2026 году классический Google/Yandex SEO даёт только часть органики; самый
быстрорастущий канал органического трафика — **AI-поисковики и ответные движки**
(ChatGPT Search, Perplexity, Claude Web Search, Google AI Overviews). Чтобы
нейросети цитировали TalkChart как первоисточник данных о Solana-токенах,
в фабрику интегрирована полная GEO-инфраструктура:

1. **Стандарт `llms.txt` и `llms-full.txt` в корне сайта (спецификация llmstxt.org):**
   - Файлы для автоматических агентов и AI-краулеров.
   - Описание проекта, правила интерпретации ончейн-метрик, инструкции цитирования.
   - `llms-full.txt` содержит полные дайджесты всех отслеживаемых пулов для
     мгновенного считывания нейросетью за один запрос без обхода десятков страниц.
2. **Машинночитаемые двойники каждой страницы (`.md` и `.json`):**
   - У каждого пула `site/pools/{addr}.html` есть чистый Markdown-двойник `{addr}.md`
     и структурированный JSON `{addr}.json`.
   - В заголовках HTML прописаны `<link rel="alternate" type="text/markdown">`
     и `<link rel="alternate" type="application/json">`.
   - Perplexity и AI-боты парсят Markdown без HTML-мусора, что в 10 раз снижает
     вероятность галлюцинаций при извлечении цифр.
3. **Блок прямого ответа (Direct Answer / TL;DR) на каждой странице:**
   - Первые 50 слов формулируют законченный прямой ответ на вопрос
     «Что такое токен X, каков его курс, объём торгов и почему он растёт?».
   - Таблица проверяемых ончейн-фактов с точным ISO-временем среза.
4. **Расширенная микроразметка Schema.org:**
   - `FAQPage` с реальными вопросами пользователей («Какая цена и объём?»,
     «Почему движется курс?», «Кто покупает (киты)?», «Безопасен ли пул?»).
     AI-поисковики напрямую берут ответы из FAQPage.
   - `Dataset` с указанием переменных (`price_usd`, `volume_h24`, `reserve_usd`)
     и даты обновления `dateModified`.
   - `FinancialProduct` с провайдером TalkChart.
5. **Файл `robots.txt` с явным разрешением AI-ботов:**
   - Разрешён доступ `GPTBot`, `ChatGPT-User`, `PerplexityBot`, `ClaudeBot`,
     `Claude-Web`, `Google-Extended`, `Applebot-Extended`, `Amazonbot`, `CCBot`, `cohere-ai`.
6. **Динамический `sitemap.xml`:**
   - Пересобирается каждый прогон фабрики, содержит все HTML и MD URL'ы с актуальными
     метками `<lastmod>` и приоритетами обхода.

## 11.7. Ревизия 5 (реализовано 2026-09-21): нативные Solana-инструменты (Jupiter + Blinks)

Интегрированы два ключевых нативных механизма экосистемы Solana для монетизации и виральности:

1. **Jupiter Terminal (DEX-своп прямо в TalkChart):**
   - Кнопка «⚡ Своп» в терминале открывает встроенный виджет Jupiter (или fallback на официальный своп).
   - Автоматически подставляет активный токен пула в поле покупки (`initialOutputMint`).
   - Позволяет пользователям торговать не покидая терминал и создаёт канал партнёрских комиссий (feeBps).
2. **Solana Actions & Blinks (виральная дистрибуция в X/Twitter):**
   - Спецификация `site/actions.json` в корне сайта (стандарт Solana Foundation / Dialect).
   - Генерация `site/api/actions/{addr}.json` для каждого пула: карточка токена, нарратив,
     кнопки мгновенного свопа через Jupiter, переход в терминал и ссылки на игры студии.
   - Дайджесты фабрики (`site/digests/`) генерируют готовую ссылку Dialect Blink (`dial.to/?action=...`),
     которая при публикации в X разворачивается в интерактивный ончейн-виджет.
   - Кнопка «🔗 Blink в X» в интерфейсе терминала для быстрого копирования ссылки для твитов.
