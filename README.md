# content-

Мобилецентричное Solana-приложение — маркетплейс микрозаданий для генерации промо-контента.
Воркеры генерируют короткие видеоклипы по брифам студии и получают внутриигровые NFT и токены.

## Текущее состояние: Фаза 1 (Discovery)

Кода нет намеренно — проект на стадии закрытия решений. Читать в таком порядке:

| Документ | О чём |
|---|---|
| [`PRD.md`](PRD.md) | требования, ончейн-схема, флоу, дорожная карта |
| [`docs/OPEN_QUESTIONS.md`](docs/OPEN_QUESTIONS.md) | реестр незакрытых решений (Q1–Q19) + верификация фактов |
| [`docs/adr/`](docs/adr/) | принятые архитектурные решения |
| [`PROGRESS.md`](PROGRESS.md) | журнал выполненных шагов |

## Структура

```
programs/   on-chain (Anchor) — пусто, старт в Фазе 2
backend/    Node.js/TS, Postgres, BullMQ — пусто, старт в Фазе 3
client/     мобайл + Wallet Adapter — пусто, старт в Фазе 4
docs/       PRD-приложения, ADR, реестр вопросов
```

## Жёсткие правила

- Никаких приватных ключей, сид-фраз и API-токенов в репозитории — только env/секрет-менеджер.
- Никакого деплоя в Solana mainnet-beta и никаких реальных переводов без явного подтверждения человека.
- Любое изменение on-chain инструкции — только с юнит- и интеграционными тестами до мержа.
- Пробел в документе, касающийся денег, юридического риска или mainnet — остановиться и спросить, а не додумывать.
