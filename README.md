# SixSec

Мобилецентричное Solana-приложение — маркетплейс микрозаданий для генерации промо-контента.
Воркеры генерируют короткие видеоклипы (до 6 секунд) по брифам студии и получают внутриигровые
NFT и токены из пула призов.

Название утверждено в [ADR-0008](docs/adr/0008-product-name-sixsec.md).

## Проверка

Локально собрать нельзя: `cargo`, `rustc`, `anchor`, `solana` и `docker` в рабочей
песочнице отсутствуют, а `crates.io` и `release.anza.xyz` из неё недоступны
(проверено — HTTP 000). Поэтому сборка и тесты выполняются в GitHub Actions:
`.github/workflows/ci.yml` ставит Solana CLI 4.1.2 и Anchor 1.2.0 из пре собранных
бинарников и прогоняет `cargo test`, `clippy` и `anchor build`.

## Жёсткие правила

- Никаких приватных ключей, сид-фраз и API-токенов в репозитории — только env/секрет-менеджер.
- Никакого деплоя в Solana mainnet-beta и никаких реальных переводов без явного подтверждения человека.
- Любое изменение on-chain инструкции — только с юнит- и интеграционными тестами до мержа.
- Пробел в документе, касающийся денег, юридического риска или mainnet — остановиться и спросить, а не додумывать.
